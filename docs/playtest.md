# Тест с друзьями

## Что нужно хосту

1. Собрать архив сборки: `powershell -ExecutionPolicy Bypass -File pack\make-pack.ps1`.
   Архив появится в `D:\Minecraft\dist`. Его нужно выложить на любой файлообменник и дать друзьям ссылку.
2. Подключение по локальной сети (так решено 2026-11-15). Все компьютеры в одной сети, друзья подключаются
   к локальному IP хоста (его показывает `ipconfig`, строка «IPv4-адрес»), порт 25565.
   Если не пускает, в брандмауэре Windows на ПК хоста нужно разрешить для Java TCP 25565 и UDP 24454 (голосовой чат).
3. Открыть мир: «Открыть для сети» с включёнными читами, порт 25565. Хост получает права на команды `/bh`.

## Порядок теста

1. Хост в тестовом мире встаёт на ровное место и вводит `/bh arena build`.
2. Друзья заходят. Хост распределяет команды: `/bh team alpha Игрок1 Игрок2`, `/bh team bravo Игрок3 Игрок4`.
3. `/bh start`. Матч идёт до 5 побед в раундах.
4. `/bh stop` останавливает матч в любой момент.

## Что проверяем

- [ ] У всех загрузилась сборка, FPS приемлемый (записать у каждого).
- [ ] Заморозка на спавне перед раундом, отсчёт, старт.
- [ ] Лут появляется в комнатах, оружие TACZ подбирается и стреляет.
- [ ] После смерти игрок смотрит глазами союзника, вещи остались на земле.
- [ ] Раунд заканчивается, когда команда уничтожена, счёт верный, следующий раунд стартует сам.
- [ ] Щиток гасит свет рядом, генератор гасит свет везде, перед новым раундом свет включается.
- [ ] Хоррор-события: шаги, шёпот, стук, мигание, помехи. Не слишком ли часто или редко?
- [ ] Рация: союзника слышно издалека, шёпот в рацию не идёт, врага рядом слышно.
- [ ] Огонь по своим выключен, ников врагов не видно.

Замечания записываем и разбираем после теста.
