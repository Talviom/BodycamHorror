BodycamHorror: как установить сборку

1. Установите Minecraft 1.20.1 с Forge 47.4.10 в своём лаунчере (например, TLauncher: версия "Forge 1.20.1").
   Один раз запустите игру и закройте, чтобы появилась папка игры.
2. Лучше сделать для сборки отдельную папку игры, чтобы не смешивать её с другими модами.
3. Распакуйте этот архив в папку игры с заменой файлов. Должны появиться папки mods, config, tacz, shaderpacks.
4. В настройках лаунчера выделите игре 6 ГБ памяти.
5. Запустите игру. Первый запуск долгий, это нормально.
6. Настройте микрофон: клавиша V открывает настройки Voice Chat.
7. Подключайтесь по адресу, который пришлёт хост (как играть из разных домов, см. ниже).

В игре:
- Говорите как обычно: команда слышит вас по рации на любом расстоянии, враг слышит, если он рядом.
- Клавиша шёпота в Voice Chat: вас слышно только вблизи и не слышно в рации.
- Шейдер включается в Настройки -> Настройки графики -> Шейдеры. На слабых видеокартах его можно выключить.

Игра из разных домов (Radmin VPN)
Обычная игра по локальной сети работает только у одного роутера. Если все сидят дома, нужна общая виртуальная сеть.
1. Все ставят бесплатный Radmin VPN с официального сайта radmin-vpn.com.
2. Хост: Сеть -> Создать сеть, придумывает имя и пароль и присылает их остальным.
3. Остальные: Сеть -> Присоединиться к сети, вводят имя и пароль. В списке должны появиться все игроки с зелёной точкой.
4. Хост заходит в мир, нажимает Esc -> Открыть для сети, ставит порт 25565 и нажимает «Открыть мир для сети».
5. Хост присылает свой адрес из Radmin VPN (вида 26.x.x.x). Остальные в игре: Сетевая игра -> Прямое подключение -> 26.x.x.x:25565.
6. Если Windows спросит про доступ Java к сети, разрешите для частных и общественных сетей. Это нужно и для игры, и для голосового чата (порт UDP 24454 у хоста).
7. Если пишет «Не удалось проверить имя пользователя», значит у хоста лицензионный аккаунт, а у друзей нет (или наоборот). Пусть все заходят через один и тот же лаунчер.
