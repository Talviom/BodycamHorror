# 0.6.0: кассета, лобби, скины команд, интерфейс. Боты 2 на 2, игрок Dev в команде Alpha (для скриншотов).
# Запуск: gradlew runClient -PbhTest=tools/tests/tape_lobby.txt
# Перед запуском в run/config/bodycamhorror-common.toml поставить roundsToWin = 2 (матч доходит до конца за 2 доставки).
# «bh arena build» в 1000 120 1000 ставит угол арены в 1002 120 1002:
#   выход Alpha 1004 120 1004 (спавны Alpha 1005..1009, 1005), выход Bravo 1040 120 1040.
# Лобби на 21 блок западнее: x 981..995, z 1002..1012; вход 988 120 1004; площадки Alpha 991 120 1009 (слева, если смотреть от входа), Bravo 985 120 1009.
# Важно: @p у команд сценария ищется от точки спавна мира (это лобби), поэтому игрока зовём по имени Dev.
# Результат: строки [bh-test] в run/logs/latest.log, в конце DONE failures=0; скриншоты в run/screenshots/060_*.png.

bh stop
bh bot remove all
execute positioned 1000 120 1000 run bh arena build
expect tape points
expect Lobby built at 988, 120, 1004

# --- лобби: боты на площадках команд, скины видны ---
execute positioned 991 120 1009 run bh bot add alpha A1

execute positioned 986 120 1008 run bh bot add bravo B2
